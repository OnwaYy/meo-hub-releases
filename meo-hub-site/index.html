FAQ

    

      
MEO Hub, c'est une IA ?Is MEO Hub an AI?
        
Non. MEO Hub est un logiciel : il organise, lance et surveille des agents Claude Code pour en tirer le maximum sur Roblox. L'intelligence vient de ton abonnement Claude, que MEO Hub ne vend pas et ne revend pas.No. MEO Hub is software: it organises, launches and watches Claude Code agents to get the most out of them on Roblox. The intelligence comes from your Claude plan, which MEO Hub neither sells nor resells.

      
Est-ce que je dois savoir coder ?Do I need to know how to code?
        
Non. Tu décris ce que tu veux, les agents écrivent le code. Lire un peu de Luau aide à vérifier, sans être obligatoire.No. You describe what you want, the agents write the code. Reading a bit of Luau helps you check, but isn't required.

      
Pourquoi mon propre abonnement Claude ?Why my own Claude subscription?
        
MEO Hub pilote Claude Code avec ton compte : tu gardes la main sur tes limites, et MEO Hub ne voit jamais tes identifiants Claude.MEO Hub drives Claude Code with your account: you control your limits, and MEO Hub never sees your Claude credentials.

      
Ça marche sur Mac ?Does it work on Mac?
        
Pas encore : MEO Hub est fait pour Windows 10 et 11.Not yet: MEO Hub is built for Windows 10 and 11.

      
Mon code reste à moi ?Does my code stay mine?
        
Oui. Ton jeu est un dossier sur ton PC. En mode Équipe, il vit dans un dépôt GitHub privé, sur ton compte.Yes. Your game is a folder on your PC. In Team mode, it lives in a private GitHub repo, on your account.

      
Combien de PC par licence ?How many PCs per licence?
        
La licence suit ton compte MEO Hub : PC fixe ou portable. En équipe, chaque membre a la sienne.The licence follows your MEO Hub account: desktop or laptop. In a team, each member has their own.

      
Et si ça ne me convient pas ?What if it isn't for me?
        
Écris-nous dans les 14 jours suivant l'achat : on te rembourse.Write to us within 14 days of purchase and we'll refund you.
